Draft title: Southern California Geological Makeup From Seismic Data
Group Members (2-3): Isaac Peck, Nina House, Maddox Chastain

✨ Motivation: I'm from southern California so this area is meaningful to me. I also think it is very interesting to try to map out the geology of an area from vibrations, even more fun if its earthquakes. 
🤔 Question and Hypothesis: Is it possible to utilize seismic data to (somewhat) effectively determine the geological makeup of a region? We hypothesize yes this is possible.
📈 How are you going to answer/test: We are going to collect data about large earthquakes from seismic stations, of which there are many, in southern california. By using data from a line of seismic stations leading from an earthquake to a specific location we believe we can find the differences between stations which we will use to determine what geology would cause such interference.  
List the types of data and some potential public data repositories that you could use to address your question.
We will be using magnitude and depth data acquired from the SCEDC and possibly other repositories if necessary.
